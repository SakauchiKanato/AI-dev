# パスワード強度診断＆生成ツール

パスワードの強度をその場で診断し、安全なパスワードを自動生成するツールです。入力したパスワードは外部に一切送信されず、すべてブラウザ内だけで計算します。

## どんな機能があるか

- パスワードを入力すると、長さ・文字種（大文字/小文字/数字/記号）・よくある弱いパターン（`password`、`123456`、`qwerty`など）や連続文字・繰り返し文字をチェックし、強度スコア（0〜100）とレベル（弱い／普通／強い／非常に強い）をリアルタイム表示
- スコアに応じた具体的な改善ヒントを表示
- 総当たり攻撃を仮定した推定解析時間の目安を表示（よくある単語を含む場合は「辞書攻撃で数秒〜数分」という注意も表示）
- 長さ・使用する文字種を指定して、安全なパスワードを一度に5件自動生成（Web Crypto APIで生成）
- 生成した候補をワンクリックでコピー（コピー成功時にトースト表示）
- 使い回し防止・2段階認証など、セキュリティの豆知識チートシートを常時表示

## 誰のためのアプリか

ネットサービスへの新規登録やパスワード変更を日常的に行う人向け。パスワードを決めるたびに「これで安全か」を毎回考え直す手間をなくします。

## いつ・どんな場面で使うか

- 新しいアカウントを作る時、安全なパスワードをその場で生成したい時
- 今使っているパスワードが安全か、変更前にセルフチェックしたい時

## 使い方

1. 上部の入力欄にパスワードを入力すると、強度スコアと改善ヒントが自動で表示されます
2. 下部の生成パネルで長さ・文字種を選び「候補を5件生成」を押すと、安全なパスワード候補が表示されます
3. 気に入った候補の「コピー」ボタンを押してそのまま使用先に貼り付けます
