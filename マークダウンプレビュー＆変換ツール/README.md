# マークダウンプレビュー＆変換ツール

Markdownをその場でリアルタイムプレビューできる、ブラウザだけで動くシンプルなツールです。

## どんな機能があるか

- Markdownを入力すると右側にリアルタイムでプレビュー表示（見出し・太字/斜体・リスト・番号付きリスト・リンク・画像・引用・コードブロック・インラインコード・水平線・テーブルに対応）
- プレビュー結果を「HTMLとしてコピー」「プレーンテキスト（記法除去）としてコピー」の2種類でクリップボードにコピー
- よく使う雛形（README雛形／議事録雛形／日報雛形）をワンクリックで挿入
- 文字数・単語数・見出し数の簡易統計表示
- 書いた内容を.mdファイルとしてダウンロード
- 入力内容は一切外部送信せず、ブラウザ内だけで処理

## 誰のためのアプリか

README・企画メモ・議事録などMarkdownで文章を書く機会が多い人向け。

## いつ・どんな場面で使うか

- READMEや議事録などを書きながら、見た目をその場で確認したいとき
- 書いた内容をブログやドキュメントツールにHTMLとして貼り付けたいとき
- Markdown記法を含む文章を、記法を取り除いたプレーンテキストとしてコピーしたいとき

## 使い方

1. `index.html` をブラウザで開く
2. 左側のテキストエリアにMarkdownを入力する（雛形を使いたい場合は上部のプルダウンから選んで「挿入」）
3. 右側にプレビューが表示されるので、必要に応じて「HTMLとしてコピー」「プレーンテキストとしてコピー」「.mdダウンロード」ボタンを使う
