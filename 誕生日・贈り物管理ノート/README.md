# 🎁 誕生日・贈り物管理ノート

友人・家族・恋人など大切な人の誕生日や記念日、贈り物の記録を管理するツールです。

## どんな機能があるか

- 人物ごとに名前・関係性・誕生日（または記念日）を登録
- 直近30日以内のイベントを近い順にダッシュボード表示（3日以内は赤、7日以内は黄で警告）
- 人物ごとに贈った／もらったプレゼントの履歴を記録（重複や傾向を把握しやすい）
- 次に贈りたい候補アイデア・予算メモを人物ごとに保存
- 「お祝い済み」にチェックすると、そのイベントは次回まで一覧から外れる
- データはブラウザに保存されないため、テキストでのエクスポート／インポートに対応
- 結果一覧をワンクリックでクリップボードにコピー

## 誰のためのアプリか

友人・家族・恋人の誕生日や記念日を忘れがちな人、贈り物が被ったりマンネリ化しがちな人向けです。

## いつ・どんな場面で使うか

- 新しい友人・知人の誕生日を知ったとき、まず登録する
- 月に1回程度アプリを開いて、直近のイベントを確認する
- 誰かにプレゼントを贈った・もらったときに履歴として記録する
- 次に何を贈るか迷ったとき、候補アイデア欄を見返す

## 使い方

1. 「人物を登録」フォームに名前・関係性・誕生日（月日）を入力して登録する
2. ダッシュボードに直近30日以内のイベントが近い順に表示されるので確認する
3. 一覧から人物を選ぶと、贈り物の履歴記録や候補アイデアのメモができる

ブラウザで `index.html` を開くだけで使えます。データを残したい場合は、閉じる前に「エクスポート」でコピーし、次回起動時に「インポート」欄に貼り付けてください。
