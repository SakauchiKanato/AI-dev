# エラーメッセージ診断ヘルパー

コンソールやターミナルに出たエラーメッセージ・スタックトレースを貼り付けると、よくある原因と確認ポイントを診断するツールです。

## どんな機能があるか

- JavaScript系（TypeError／ReferenceError／SyntaxError／RangeError等）とPython系（Traceback／KeyError／IndexError／ModuleNotFoundError／IndentationError等）の代表的なエラーパターンをヒューリスティックに検出
- 検出した種別ごとに「よくある原因」「確認・対処のヒント」をカード表示
- 同じエラーが複数回出ている場合は回数もあわせて表示
- どのパターンにも一致しない場合は「未知のパターン」として、デバッグの最初の一手（行番号の特定・直前の変更点の確認・エラーメッセージでの検索）を案内
- よくあるエラーの早見表（チートシート）を常時表示
- 診断結果をワンクリックでクリップボードにコピー

## 誰のためのアプリか

ほぼ毎日開発をする人向け。エラーに遭遇した直後、原因の見当をつける最初の一手として使います。

## いつ・どんな場面で使うか

コンソールやターミナルにエラーが出たとき、貼り付けてすぐに「何のエラーで、何を確認すればいいか」の見当をつけたいときに使います。

## 使い方

1. `index.html` をブラウザで開く
2. エラーメッセージ・スタックトレースを左のテキストエリアに貼り付けて「診断する」を押す
3. 右側に表示された診断結果を確認する（必要なら「結果をコピー」でコピー）

※ ヒューリスティック（パターンマッチ）による診断のため、あくまで参考情報です。登録済みパターンに一致しない場合は「未知のパターン」として一般的な確認手順を案内します。
