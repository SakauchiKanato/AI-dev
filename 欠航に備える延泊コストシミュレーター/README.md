# 欠航に備える延泊コストシミュレーター

台風で帰りの便が欠航したら、何泊延びていくらかかるのか。前倒しで帰るべきかを、お金と予定への影響で比べられるツールです。

## どんな機能？
- 帰りの交通手段（飛行機・フェリー・高速バス・新幹線など）と台風の影響予報から、欠航確率の目安を表示
- 宿泊費・食費・バイト等の逸失収入・振替手数料から、楽観／標準／悲観の延泊コストを試算
- 前倒し帰宅案と比べて「前倒し優先／締切を決めて備える／予定どおり」を判定
- 予備費の目安、チェックリスト、バイト先・学校向けの連絡文をコピー

## 誰のため？
台風シーズンに離島や遠方へ旅行・帰省していて、帰りの便が欠航しそうな学生や家族。

## 使い方
1. index.html をブラウザで開き、交通手段・台風の影響予報・荒天が続く日数を選ぶ
2. 宿泊費・食費・逸失収入などを入力して「試算する」を押す
3. 判定・予備費・連絡文を確認し、必要ならコピーして使う

## 注意
欠航確率は一般的な傾向をもとにした仮の目安です。実際の運航は運航会社と気象庁の最新情報で必ず確認してください。データは端末に保存されません。
