# ゴミ出し忘れ防止プランナー

一人暮らしで、ゴミの分別・収集曜日（燃えるごみ・資源ごみ・隔週の缶びんペットボトルなど）を覚えきれず出し忘れがちな人のための管理ツールです。

## どんな機能があるか

- ゴミの種類ごとに名前・色・収集パターン（毎週の曜日、または隔週の「第◯曜日」）・メモを登録
- 「今日」「明日」出せるゴミを大きく表示するダッシュボード
- 本日が収集日なのに「出した」を記録していない品目があれば出し忘れ警告を表示
- 今日から7日間の週間カレンダーで収集予定を一覧表示
- 「出した」ボタンで記録し、品目ごとの遵守率（記録日数／収集予定日数）を統計表示
- 登録内容をテキストでエクスポート／インポート（ブラウザに保存しないため、次回開くときに貼り付けて復元）

## 誰のためのアプリか

一人暮らしの大学生など、地域ごとに異なるゴミ収集ルールを覚えるのが大変な人向け。

## いつ・どんな場面で使うか

毎朝、または前夜に「今日・明日出せるゴミ」を確認したいときに使います。

## 使い方

1. 「ゴミの種類を登録」フォームで、種類名・色・収集パターン（毎週／隔週）を選んで登録する
2. 上部のダッシュボードで今日・明日出せるゴミを確認し、出したら「出した にする」ボタンを押す
3. 次回もデータを引き継ぎたい場合は、下部の「エクスポート」でテキストをコピーして保存し、次回開いたときに「インポート」に貼り付ける

このアプリはブラウザのストレージを使わないため、ページを閉じると登録内容は消えます。継続して使う場合は必ずエクスポートしてください。
