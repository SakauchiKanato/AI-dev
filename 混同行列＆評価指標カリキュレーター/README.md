# 📊 混同行列＆評価指標カリキュレーター

分類モデルの結果（混同行列・ラベル列・予測スコア）から、Accuracy / Precision / Recall / F1 / MCC などの評価指標をまとめて計算する単一HTMLツール。

## 誰のためのアプリか

機械学習を学んでいる大学生・エンジニア向け。評価指標を手計算するのが面倒なときや、「不均衡データだと Accuracy が高くても当てにならない」ことを数字で確かめたいときに使えます。

## 主な機能

- **① 2値（TP/FP/FN/TN）**: 混同行列の4マスを入れると Accuracy・Precision・Recall・Specificity・F1・Fβ（β編集可）・MCC・Balanced Accuracy を計算。各指標の式と意味も表示。クラスが不均衡なときは注意メッセージを出す
- **② ラベル列から集計**: 正解ラベルと予測ラベル（0/1）を貼り付けると混同行列を自動集計
- **③ 閾値シミュレーション**: 予測スコア（0〜1）と正解ラベルを貼り付け、スライダーで閾値を動かすと混同行列と指標がリアルタイムに変わる。閾値 0.1〜0.9 の Precision / Recall / F1 一覧表付き（行クリックでその閾値へジャンプ）
- **④ 多クラス（3〜6クラス）**: クラス名を編集できる混同行列から、クラス別 Precision / Recall / F1 とマクロ平均・マイクロ平均（= Accuracy）・重み付き平均F1 を計算
- 0除算になる指標は「定義不能」と表示
- 結果をワンクリックで **Markdown表としてコピー**（レポートやノートに貼れる）
- 各タブにサンプルデータ付き。入力データは外部に送信されず、ブラウザ内だけで処理

## 使い方

1. `index.html` をブラウザで開き、上のタブから入力方法を選ぶ（迷ったら「サンプル」ボタン）
2. 件数・ラベル列・スコアなどを入力して「計算する／集計する／読み込む」を押す
3. 結果の指標カードを確認し、必要なら「Markdown表でコピー」で貼り付ける

## 補足

- 区切り文字はカンマ・空白・改行・読点のどれでもOK。ラベルは `0/1`（`true/false` も可）
- 閾値は「スコア ≧ 閾値 で陽性」と判定
- データは保存されません（ページを閉じると消えます）
