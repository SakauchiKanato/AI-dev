# 円安家計インパクトシミュレーター

為替（円/ドル）が変動すると、自分の家計にどれくらい影響するのかをざっくり試算するツールです。「円安が進んでいる」というニュースを見ても実感が湧きにくい時に、数字でイメージするために使います。

## どんな機能があるか

- 基準レート（自分が意識していた頃の円/ドル）と現在レートを入力すると、円安の進行度（%）を表示
- 支出カテゴリ（食料品・光熱費・海外通販・家電など）ごとに月額支出と「輸入依存度（%）」を登録
- 現在の為替水準での追加負担額（月額）を自動計算
- 為替が1円動くごとの負担額の感応度を表示
- 今後の為替シナリオ（150円〜170円）ごとの追加負担額・年間換算額の比較表
- 結果をMarkdown表としてワンクリックでコピー（クリップボード非対応環境ではフォールバック）
- 登録データのテキストエクスポート/インポート（ブラウザストレージは使わないため、次回開いた時は貼り付けて復元）

## 誰のためのアプリか

一人暮らしの学生・社会人など、円安のニュースを見て「自分の生活費にどう関係あるか分からない」と感じている人向けです。海外通販や留学・輸入家電などの支出が気になる場面でも使えます。

## いつ・どんな場面で使うか

- 為替レートのニュースを見た時に、自分ごととして負担額を確認したい時
- 家計の中で「為替の影響を受けやすい支出」を把握し、対策（節約・買い時の見極め）を考えたい時

## 使い方

1. 「① 為替レートの設定」で基準レートと現在レートを入力する
2. 「② 支出カテゴリごとの輸入依存度を登録」でカテゴリを追加する（「主要カテゴリを一括で追加」ボタンで簡単に始められる）
3. 「③ 現在の負担インパクト」「④ 今後のシナリオ比較」で結果を確認し、必要なら「結果をMarkdown表でコピー」で保存する
