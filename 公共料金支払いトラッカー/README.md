# 公共料金支払いトラッカー

電気・ガス・水道・家賃・NHK受信料など、支払いサイクルも金額もバラバラな固定費の「払い忘れ」「口座振替の残高不足」を防ぐためのツールです。

## どんな機能があるか

- 支払い項目（名称・金額・支払い方法・支払いサイクル・次回支払い予定日）を登録できます
- 支払い期限が近い順にダッシュボード表示し、期限が近いものは黄色、当日・期限切れは赤色で警告します
- 口座振替の項目について、今月使える残高を入力すると、今月の振替予定合計と比較して不足していないかチェックします
- 「支払った」ボタンで記録すると、今月の固定費支出合計が集計され、次回の支払い予定日が自動的に繰り上がります
- 電気・ガスなど金額が毎回変わる項目は、支払うたびに履歴が残り、平均額や前回との差額が確認できます
- データはブラウザに保存されないため、テキストでエクスポート／インポートして次回に持ち越せます

## 誰のためのアプリか

一人暮らしをしている人（特に固定費の支払いサイクルがバラバラで把握しづらい大学生・新社会人など）向けです。

## いつ・どんな場面で使うか

- 月初に「今月何をいつまでに払うか」を確認するとき
- 口座に入金する前に「今月いくら引き落とされるか」を確認したいとき
- 電気代・ガス代など変動費が前回よりどれくらい増減したか把握したいとき

## 使い方

1. 「支払い項目を登録」フォームに、名称・金額・支払い方法・支払いサイクル・次回支払い予定日を入力して登録します
2. ダッシュボードに登録した項目が期限順に並ぶので、期限が近いものから確認します
3. 支払いを済ませたら「支払った」ボタンを押すと記録され、次回の予定日が自動で更新されます
4. 次回また使うときは「エクスポート（コピー）」でデータをコピーしておき、次回開いたときにテキストエリアに貼り付けて「このテキストから読み込む」を押してください
