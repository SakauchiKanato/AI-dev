# 終電プランナー

外出先で「そろそろ出ないと終電に間に合わない」タイミングを逆算して教えてくれるツールです。

## どんな機能があるか

- 路線名・終電時刻・列車の間隔を登録し、複数の路線を管理できます
- 今いる場所から駅までの移動時間と余裕（バッファ）時間を入力すると、「出発すべき時刻」を自動で逆算します
- 出発時刻までの残り時間をカウントダウン表示し、残り30分／15分／5分を切ると警告色に変化します
- 終電だけでなく1本前・2本前の候補列車も一覧表示し、余裕を持って帰る選択肢を確認できます
- よく行く行き先（例: 友人宅・実家）と移動時間をプリセット登録し、次回から呼び出せます
- 計算結果をワンクリックでクリップボードにコピーできます

## 誰のためのアプリか

一人暮らしの大学生など、飲み会や友人との外出時に終電を逃した経験がある人向けです。

## いつ・どんな場面で使うか

外出先でそろそろ帰り時を考え始めたタイミングで開き、路線と移動時間を入力するだけで使えます。

## 使い方

1. 「① 路線・終電の設定」で路線名・終電時刻・列車の間隔を入力して「路線を追加」を押す
2. 登録した路線をクリックして選択する
3. 「② 出発逆算タイマー」で駅までの移動時間・余裕時間を入力すると、出発すべき時刻とカウントダウンが表示される

行き先ごとの移動時間はプリセットとして登録しておくと、次回から選ぶだけで入力できます。
