# 資格試験対策プランナー

試験日までの残り日数から「今日どれだけ勉強すべきか」を自動で逆算し、分野別の学習進捗と週間ペースを見える化するツールです。

## どんな機能があるか

- 試験ごとに試験日・1日に確保できる学習時間・出題分野（分野名と目標学習時間）を登録
- 試験日までの残り日数と分野の目標時間から、今日確保すべき学習時間の目安を自動計算
- 分野別の学習進捗をバーで表示（記録時間 / 目標時間）
- 直近7日間の学習時間を棒グラフ表示し、ペースが遅れている日を色で警告
- 模試・過去問のスコアを記録して一覧表示
- 複数の試験を登録した場合は試験日が近い順に一覧表示し、残り3日以内は⚠で強調
- データはテキストでエクスポート／インポートして保存（ブラウザには保存されません）

## 誰のためのアプリか

基本情報技術者・TOEIC・簿記など、就活や自己研鑽のために資格試験を受ける大学生向け。

## いつ・どんな場面で使うか

- 試験を申し込んだ直後、学習計画を立てるとき
- 毎日の学習後、ログを記録するとき
- 試験直前、今のペースで間に合うか確認したいとき

## 使い方

1. 「試験を登録」で試験名・試験日・1日に確保できる学習時間・出題分野（分野名と目標学習時間）を入力して登録する
2. 一覧から試験を選ぶと、今日の学習目安と分野別進捗が表示される
3. 学習が終わったら「学習ログを記録」で日付・分野・時間を入力して記録する（模試を受けたら「模試・過去問スコア」にも記録できる）

データはブラウザに保存されないため、閉じる前に「エクスポート」でテキストを保存し、次回開いたときに「インポート」で貼り付けてください。
