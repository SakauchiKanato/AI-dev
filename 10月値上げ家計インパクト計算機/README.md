# 10月値上げ家計インパクト計算機

10月の値上げが自分の家計にどれだけ響くかを、費目ごとの月の支出と想定値上げ率から試算するツールです。

## どんな人向け
一人暮らしの大学生など、物価高で毎月の出費が気になる人。

## できること
- 費目（食費・日用品・光熱費など、追加・削除可）ごとに支出と値上げ率を入力
- 月・年間の増加額、値上げ後の月支出を自動計算
- 手取りに占める割合、バイト何時間分かを表示
- 増加額が大きい費目のランキング、節約でカバーした場合の残り負担
- 結果のMarkdownコピー、入力データの書き出し／読み込み

## 使い方
1. 費目ごとに月の支出と想定値上げ率（初期値は仮置きの目安）を入力
2. 手取り月収・時給・節約割合を入力（任意）
3. 右側の結果を確認し、必要なら「結果をMarkdownでコピー」

## 注意
値上げ率は公式データではなく目安です。実際の価格や公式発表で調整してください。ブラウザには保存しないため、次回は書き出したテキストを貼り付けて復元します。
