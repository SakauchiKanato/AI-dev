# Cron式ビルダー＆解説ツール

スケジュール式（cron式）を組み立てたり、既存のcron式が何を意味するか読み解いたりできるツールです。

## どんな機能があるか

- **ビジュアルで作る**: 分・時・日・月・曜日の5項目をそれぞれ「毎」「値を指定」「範囲」「n刻み」から選んでcron式を組み立てられます（曜日はチェックボックスで直感的に選択）
- **直接入力**: 既存のcron式を貼り付けると自動で解析します
- **日本語での解説**: 生成・解析したcron式を「平日 9時00分 に実行」のような日本語の文章に変換して表示します
- **次回実行予定**: 今の時刻から先の実行予定を5件計算して一覧表示します
- **プリセット**: 「毎日9時」「平日9時」「15分おき」などのよくあるパターンや、AIオフィス自身の定例（朝会・昼会・夜会・週報）の時刻をワンクリックで反映できます
- **チートシート**: `*` `,` `-` `/` の意味を常時表示
- 入力ミス（範囲外の値・書式ミスなど）はエラーメッセージで通知します
- 組み立てたcron式はワンクリックでクリップボードにコピーできます

## 誰のためのアプリか

日常的に開発・タスク自動化をする人（cronやスケジュールタスクの設定を書く機会がある人）向けです。

## いつ・どんな場面で使うか

- 自分でスケジュールタスクのcron式を書きたいけれど、書式をいつも忘れてしまう時
- 誰かが書いたcron式や、既存の設定を見て「これはいつ実行されるのか」を確認したい時

## 使い方

1. 「ビジュアルで作る」タブで各項目を選ぶか、「直接入力」タブにcron式を貼り付ける
2. 中央に表示される日本語の説明文と、次回実行予定の一覧を確認する
3. 「コピー」ボタンで完成したcron式をコピーして使う
