# テキスト差分チェッカー

2つのテキストを貼り付けるだけで、変わった行をすぐに見つけられるブラウザツールです。

## どんな機能があるか

- 「変更前」「変更後」の2つのテキストエリアに文章・コードを貼り付けて比較
- 行単位で「追加」「削除」「変更なし」を色分け表示（追加=緑、削除=赤）
- 並列表示（左右に並べて比較）と統合表示（unified diff風の1カラム表示）をタブで切り替え
- 追加・削除・変更なしの行数をダッシュボードで一目で確認
- 「大文字・小文字を区別しない」「行頭・行末の空白を無視」の比較オプション
- 差分結果をunified diff形式でワンクリックコピー
- サンプルボタンで動作イメージをすぐ確認できる

## 誰のためのアプリか

コードや文章の変更前後を見比べたい人（かなとさん含む）向け。修正前後のコード、AIの生成結果の違い、設定ファイルの変更点などをサッと確認したい場面に。

## いつ・どんな場面で使うか

- コードを書き換えたあと、元のバージョンと何が変わったか確認したいとき
- AIに同じお題を2回投げて、出力の違いを見比べたいとき
- 設定ファイルやドキュメントの変更点をレビューしたいとき

## 使い方

1. `index.html` をブラウザで開く
2. 「変更前」「変更後」の欄にそれぞれテキストを貼り付ける（必要なら比較オプションをON）
3. 「比較する」ボタンを押すと、差分が並列表示・統合表示の両方で確認できる。「差分をコピー」でunified diff形式のテキストをコピーできる

## 技術メモ

- 単一HTMLファイル（外部ライブラリなし）
- 行差分はLCS（最長共通部分列）アルゴリズムをJavaScriptで実装
- ブラウザストレージ（localStorage等）は使用せず、状態はJS変数のみで保持
