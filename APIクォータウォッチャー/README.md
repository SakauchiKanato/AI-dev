# APIクォータウォッチャー

AI APIのレート制限（1分あたり・1日あたりの呼び出し上限）に対して、あと何回呼び出せるかをその場で確認できるツールです。

## どんな機能があるか

- Claude API・OpenAI API・Gemini APIなど、サービスごとに「1分あたりの上限」「1日あたりの上限」を登録・編集（プリセット値入り、自由に追加も可能）
- 「呼び出した」ボタンを押すたびに記録し、直近1分間・本日の使用回数を自動集計
- 上限に対する使用率をバーで表示し、80%以上は黄色・100%到達は赤で警告
- 1分あたりの上限に達した場合、次に枠が空くまでの秒数をカウントダウン表示
- 直近20件の呼び出しログを時刻付きで一覧表示
- 複数サービスをタブで切り替えて管理
- 設定・ログをテキストでエクスポート／インポート（ブラウザの保存機能は使わないため、次回開いたときは貼り付けて復元）

## 誰のためのアプリか

AI APIをほぼ毎日呼び出して開発・検証をしている人向け。特に、レート制限にたびたび引っかかってしまう人に向いています。

## いつ・どんな場面で使うか

APIを使った開発・検証作業中に、別タブでこのツールを開いておき、呼び出すたびに「呼び出した」ボタンを押すことで、制限に近づいていないかをリアルタイムに確認できます。

## 使い方

1. `index.html` をブラウザで開く
2. 上部のタブでサービスを選び、1分あたり・1日あたりの上限を入力する（初期値のままでもOK）
3. APIを呼び出すたびに「呼び出した」ボタンを押して記録する。ダッシュボードの残り回数・警戒度・カウントダウンを見ながら使用ペースを調整する

作業を終える前に「エクスポート」でデータをコピーしておき、次回開いたときに貼り付けて「インポート」すれば続きから使えます。
