# 荒天お休み判断＆連絡文メーカー

台風・大雨の日に、大学の授業やバイトへ「行く／時間をずらす／休む」の目安を出し、連絡文まで作れるツールです。

## どんな機能があるか

- 警報の有無・警戒レベル・電車の運行状況・移動手段・帰りの天気などを選ぶと、予定ごとにリスク点数と3段階の判断（行けそう／時間をずらす／休む方向）を理由つきで表示
- 大学・バイト・その他の予定を最大20件まで登録して、まとめて判断
- 欠席・遅刻・休んでよいかの相談、の3種類の連絡文を自動生成（宛先・名前・理由・到着見込みを編集可能）
- 判断結果と連絡文をワンクリックでコピー

## 誰のためのアプリか

台風や大雨の日に、通学やバイト出勤をどうするか迷い、連絡文の書き方にも悩む大学生向けです。

## いつ・どんな場面で使うか

台風接近の前日夜〜当日朝に、最新の予報や運行情報を見ながら使います。判断はあくまで目安なので、最終的には学校・職場・気象庁・鉄道会社の公式情報で確認してください。

## 使い方

1. 「荒天の状況」で警報・電車の状況などを選ぶ
2. 「予定を追加」で授業やバイトを登録する
3. 判断結果を確認し、予定をクリックして連絡文をコピーする
