# ☕ カフェイン摂取量トラッカー

コーヒー・エナジードリンク・お茶などのカフェイン摂取を記録し、今日どれくらい摂ったか、就寝時にどれくらい影響が残っているかをすぐ確認できるツールです。

## どんな機能があるか

- コーヒー・エナジードリンク・紅茶・緑茶・コーラ・カフェイン錠剤などのプリセットをワンクリックで記録（カフェイン量は編集可能、カスタム飲み物も追加可）
- 本日の累計摂取量と、推奨上限（デフォルト400mg、変更可）に対する使用率をダッシュボード表示（80%以上は黄色、100%超は赤で警告）
- カフェインの半減期（デフォルト5時間、変更可）をもとに「今、体内にどれくらい残っているか」「今夜の就寝予定時刻にどれくらい残っているか」を自動計算
- 就寝時の推定残存量に応じて「少ない／やや残る／影響大」のバッジ表示
- 直近7日間の日別摂取量をグラフで表示
- 記録・設定をテキストでエクスポート／インポート（ブラウザに保存しないため、次回も使う場合はテキストを保存しておく）

## 誰のためのアプリか

深夜まで開発作業をすることが多く、コーヒーやエナジードリンクに頼りがちな人向け。カフェインの摂りすぎや、寝る前に効果が残って寝つきが悪くなるのを避けたい人におすすめです。

## いつ・どんな場面で使うか

- 作業中にコーヒーやエナジードリンクを飲むたびに記録する
- 夜、「今から寝て大丈夫か」を確認したい時に使う

## 使い方

1. `index.html` をブラウザで開く
2. 飲んだ飲み物のボタンを押す（またはカスタム欄に飲み物名とカフェイン量を入力して「記録する」）
3. ダッシュボードで本日の累計・上限に対する使用率・就寝予定時刻の残存量を確認する

次回も使う場合は「エクスポート」でテキストを保存し、起動時に「取り込む」欄に貼り付けてください。
