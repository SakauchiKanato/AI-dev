# 単位取得プランナー（卒業要件シミュレーター）

大学の卒業要件（必修・選択必修・選択・自由選択など）に対して、今どれだけ単位を取得できているかとGPAを一目で把握できるツールです。

## どんな機能があるか

- カテゴリ（必修／選択必修／選択／自由選択など、名称・必要単位数は自由に編集可能）ごとの卒業要件単位数を登録
- 履修した科目を科目名・単位数・カテゴリ・評価（S/A/B/C/D）・学期で登録
- カテゴリ別の取得単位数・充足率を進捗バーで表示し、不足しているカテゴリを警告表示
- 全科目の評価からGPAを自動計算（単位数による加重平均、評価とGPA換算値は編集可能）
- 学期ごとの取得単位数をグラフで表示
- 総必要単位数に対する全体進捗と、残り学期数を入力すると「卒業までに1学期あたり必要な単位数」を逆算表示
- 登録データはテキストでエクスポート／インポート可能（ブラウザの保存機能は使わないため、次回開くときはエクスポートしたテキストを貼り付けて復元してください）
- 結果一覧をワンクリックでクリップボードにコピー

## 誰のためのアプリか

卒業要件・単位・GPAの管理をしたい大学生向けです。

## いつ・どんな場面で使うか

履修登録が終わった直後や、成績が出た学期末に、カテゴリごとの充足状況とGPA、卒業までのペースを確認したいときに使います。

## 使い方

1. まず①でカテゴリ（必修・選択必修など）と必要単位数を確認・編集する（初期値は一般的な例、実際の卒業要件に合わせて変更してください）
2. ②のフォームから履修した科目を1件ずつ登録する（お試しで動きを見たい場合は「サンプルデータを読み込む」ボタンも使えます）
3. ①の全体ダッシュボードでGPAと充足率を確認し、⑤で残り学期数を入力すると卒業までのペースが分かります

データはブラウザを閉じると消えるため、⑥のエクスポート機能で控えを保存しておくことをおすすめします。
