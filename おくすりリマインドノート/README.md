# おくすりリマインドノート

薬・サプリの飲み忘れをその場で防ぐ、服薬管理ノート。

## どんなアプリ？

毎日決まった時間に薬やサプリを飲む必要があるのに、忙しさやうっかりで飲み忘れてしまう——そんな悩みを解消するツールです。服用タイミングごとにチェックリストが表示され、時間を過ぎても未チェックの項目には警告が出ます。

## 主な機能

- 薬・サプリ名と服用タイミング（朝食後／昼食後／夕食後／就寝前／カスタム時刻）を登録
- 本日の服用チェックリストをタイミング別に表示、ワンタップで「飲んだ」を記録
- 服用時刻を過ぎても未チェックの項目に飲み忘れ警告を表示
- 直近7日間の達成率をヒートマップで可視化
- 飲み忘れが多い薬をランキング表示し、対策のヒントを提示
- 登録データ・記録をテキストでエクスポート／インポート（ブラウザに保存しないため、次回開く時に貼り付けて復元）

## 誰のためのアプリ？

一人暮らしなどで誰にもリマインドしてもらえず、薬・サプリ・アレルギー薬の飲み忘れが気になる人向け。

## いつ使う？

- 朝食後・昼食後・夕食後・就寝前など、服用タイミングのたびに開いてチェック
- 薬が増えた時・新しいサプリを始めた時の登録

## 使い方

1. 「薬・サプリを登録」フォームで名前と服用タイミングを入力して登録する
2. 上部の「今日の服用チェックリスト」から飲んだら「飲んだ」ボタンを押す
3. 閉じる前に「エクスポート/インポート」パネルでデータをコピーして保存し、次回開いた時に貼り付けて復元する

## 注意

- ブラウザのストレージを使わないため、ページを閉じるとデータは消えます。継続して使う場合は毎回エクスポート・インポートしてください。
- 医療行為の代わりにはなりません。実際の服薬管理は医師・薬剤師の指示に従ってください。
