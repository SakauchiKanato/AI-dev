# ⚡ 節電シミュレーター

家電の消費電力から月間の電気代を試算し、「どの家電をどれだけ減らせば節約になるか」を見える化するツールです。

## どんな機能があるか

- 家電ごとに「名前・消費電力(W)・1日の使用時間(h)・台数」を登録
- 登録した家電の月間消費電力量(kWh)と電気代を自動計算（電力単価は円/kWhで自由に編集可、デフォルト31円）
- 電気代が高い順にランキング表示し、一番負担の大きい家電を強調表示
- 家電ごとに「使用時間をどれだけ減らすか」をスライダーで試し、削減額をリアルタイム表示
- 目標節約額を入力すると、シミュレーション結果との差分（達成／不足）を表示
- 登録データをテキストでエクスポート・インポート可能（ブラウザに保存しないため、次回開いたら貼り付けて復元）

## 誰のためのアプリか

一人暮らしなどで電気代を減らしたい人向け。「なんとなく高い気がする」を、家電単位の数字に落とし込んで具体的な節約行動につなげます。

## いつ・どんな場面で使うか

- 電気代の請求書を見て「今月ちょっと高いな」と感じたとき
- エアコンや冷蔵庫など、どの家電から見直せば効果が大きいか知りたいとき
- 「あと◯◯円節約したい」という目標がある月の計画づくり

## 使い方

1. 上部の「電力単価」「目標節約額」を必要なら編集する
2. 「家電を登録」フォームに家電名・消費電力・1日の使用時間・台数を入力して「追加する」
3. ランキング表で電気代の高い家電を確認し、下部のシミュレーションでスライダーを動かして削減額を試す
4. 作業を終える前に「エクスポート」でデータをテキスト化し、次回開いたときに貼り付けて「インポート」すれば続きから使えます

## 注意事項

- 入力したデータは外部送信せず、ブラウザ内のみで処理します
- ブラウザストレージ（localStorage等）は使用していないため、ページを閉じると登録内容は消えます。必要に応じてエクスポートしたテキストを保存しておいてください
- 消費電力量・電気代は目安の概算値です（30日/月として計算）
