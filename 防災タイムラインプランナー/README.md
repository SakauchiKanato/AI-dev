# 防災タイムラインプランナー

台風・大雨の接近時に「今、何をすべきか」を時系列で可視化する、マイ・タイムライン作成ツールです。

## どんな機能があるか

- 台風・大雨の接近予想時刻を入力すると、72時間前〜3時間前までの行動タイムライン（情報収集・非常品点検・買い出し・避難先確認・避難準備・避難判断）を自動生成
- 気象庁の警戒レベル（1〜5）をボタンで選ぶと、現在とるべき行動をハイライト表示
- 住居の階数・周辺リスク（河川近く／低地／土砂災害警戒区域）を選ぶと、早めの行動が必要な項目を強調表示
- 各行動に「完了」チェックを付けて進捗を管理
- 避難先・同居人への連絡状況をメモできる
- タイムライン全体をワンクリックでクリップボードにコピー

## 誰のためのアプリか

台風・大雨の接近時に、避難や備えのタイミングの判断に迷いがちな一人暮らしの方向け。

## いつ・どんな場面で使うか

台風接近や大雨警報が出たとき、気象庁の発表を見ながら「今のうちに何をすべきか」を整理したいときに使います。

## 使い方

1. 台風・大雨の接近予想時刻を入力する（未入力でも「接近◯時間前」形式でタイムラインは表示されます）
2. 現在の気象庁警戒レベルをボタンで選択する
3. 住居の階数・周辺リスクを選び、表示されたタイムラインの項目をチェックしながら行動する

※このアプリは目安の行動計画を提示するものです。実際の避難判断は必ずお住まいの自治体からの避難情報を最優先してください。入力内容は外部に送信されず、ブラウザ内のみで処理されます。
