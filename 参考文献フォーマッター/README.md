# 参考文献フォーマッター

大学のレポート・卒論で使う参考文献リストを、書式を調べ直さずにサクッと作れるツールです。

## どんな機能があるか

- 文献の種類（書籍／論文／Webページ／ニュース記事）ごとに必要な項目を入力するだけで、参考文献の形式に整形
- 引用スタイルは「APA第7版」「MLA第9版」「SIST02（日本語論文形式）」の3種類から選択でき、スタイルを切り替えると登録済みの全文献が自動で書き換わる
- 複数の文献を登録してリスト管理。著者名（50音・アルファベット）順に自動で並び替え
- 本文中で使う「（著者, 年）」形式の短縮引用もあわせて生成
- 必須項目が未入力のまま登録すると、リスト上に⚠マークで警告表示（何が足りないか分かる）
- リスト全体をワンクリックでクリップボードにコピー

## 誰のためのアプリか

大学のレポートや卒論で参考文献リストを手打ちで整形している学生向け（かなとさん含む）。

## いつ・どんな場面で使うか

- レポート提出前に、参照した書籍・論文・Webページ・ニュース記事をまとめて正しい書式で書き出したいとき
- 授業やゼミごとに指定される引用スタイルが違っていて、その都度書き方を調べ直すのが面倒なとき

## 使い方

1. `index.html` をブラウザで開く
2. 左側で文献の種類を選び、著者・タイトルなどの情報を入力して「リストに追加」
3. 右上で引用スタイル（APA／MLA／SIST02）を選ぶと、右側にリストと短縮引用が表示されるので「リストをコピー」でレポートに貼り付け

## 技術メモ

- 単一HTML（外部ライブラリ不使用）。ブラウザで開くだけで動作
- 状態はJS変数で保持（ブラウザストレージ不使用）。ページを閉じるとリストは消えるため、コピーしてレポート側に保存する運用
