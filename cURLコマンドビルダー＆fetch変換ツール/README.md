# cURLコマンドビルダー＆fetch変換ツール

APIの動作確認のたびにcURLコマンドの書式を調べ直したり、確認できたcURLをJavaScriptのfetch()コードへ手作業で書き直したりする手間をなくす、ブラウザだけで動く単一HTMLツールです。

## どんな機能があるか

- URL・HTTPメソッド・ヘッダー・認証（Bearer Token／Basic認証／カスタムAPIキー）・JSONボディをフォームで入力すると、cURLコマンドとJavaScriptのfetch()コードをリアルタイムに生成
- 既存のcURLコマンドを貼り付けると自動解析し、URL・メソッド・ヘッダー・認証・ボディをフォームに復元（未対応のオプションは無視した旨を表示）
- Claude API／GitHub API／シンプルなGETのプリセットをワンクリックで挿入
- 生成結果（cURL／fetchコード）をワンクリックでクリップボードにコピー
- 入力内容は一切外部送信せず、ブラウザ内のみで処理

## 誰のためのアプリか

ほぼ毎日開発をする人（APIの動作確認を頻繁に行う開発者）向け。

## いつ・どんな場面で使うか

- 新しいAPIを試す時、curlコマンドをその場で組み立てたい時
- ターミナルで動作確認したcurlコマンドを、コードに組み込むためfetch()に変換したい時
- 他の人が送ってきたcurlコマンドの中身（ヘッダーやボディ）をぱっと確認したい時

## 使い方

1. `index.html` をブラウザで開く
2. 左側のフォームにURL・メソッド・ヘッダー・認証・ボディを入力する（または上部のプリセットボタンで例を読み込む）
3. 右側にcURLコマンドとfetch()コードがリアルタイムで表示されるので、タブを切り替えて「結果をコピー」でクリップボードにコピーする

既存のcURLコマンドを解析したい場合は、フォーム下部の貼り付け欄にコマンドを貼り付けて「解析してフォームに反映」を押してください。

## 注意事項

実際のAPIトークンやパスワードを入力する際は、画面共有時などの表示にご注意ください（このツール自体は外部送信を行いません）。
