# 提出トラブル記録＆連絡文メーカー

LMSやClassroomの不具合で課題が提出できない時に、「いつ・何が起きたか」の記録メモと、先生・学務課への連絡文のたたき台を作るツールです。

## 機能
- 科目・課題・締切・気づいた日時・症状・エラー文言・試したことを入力
- 記録メモ／先生向け連絡文／学務課向け連絡文／証拠チェックリストを生成
- 締切の前か後かで文面を自動で切り替え
- 各内容をワンクリックでコピー（クリップボード失敗時のフォールバックあり）

## 誰のため・いつ使う
締切間際にシステム不具合や通信トラブルで提出できなかった、またはできなさそうな大学生が、慌てずに連絡と記録を整えたい時に。

## 使い方
1. `index.html` をブラウザで開き、科目名・課題名などを入力（科目名と課題名は必須）
2. 「記録と連絡文を作る」を押し、タブで内容を切り替える
3. 「この内容をコピー」で貼り付け先へ。送る前に必ず読み返して直してください

## 注意
- 入力内容は画面内だけで扱い、保存・送信しません（再読み込みで消えます）
- 連絡文はたたき台です。課題が手元に完成している等の事実は「補足」欄に自分で書き足してください
- 提出の扱いは先生・大学の判断に従ってください
