# 🌱 エコ生活CO2セーブトラッカー

日々の「エコな選択」を記録して、積み重なったCO2削減量を可視化するツールです。

## どんな機能があるか

- 交通・食事・買い物・エネルギー・ゴミ/リサイクルの5カテゴリで、あらかじめ用意されたエコ行動（自転車移動・マイバッグ使用・エアコン調整など）をチェックするだけで、その日のCO2削減量を自動集計
- 累計の削減量を、杉の木の年間吸収量換算・ガソリン消費量換算という分かりやすい単位でも表示
- エコ行動を実施した日が続くほどカウントされる「継続日数」表示
- 週間・月間の削減量推移を棒グラフで表示
- 自分だけのエコ行動をカテゴリ・削減量つきで自由に追加可能
- 記録したデータはテキスト形式でエクスポート／インポートでき、次回もテキストを貼り付けるだけで続きから再開できる（ブラウザの保存機能は使用していません）
- 結果はワンクリックでクリップボードにコピー可能

## 誰のためのアプリか

環境に配慮した暮らしを意識したい人向け。日々の小さなエコ行動を「見える化」して続けるモチベーションにしたい方に使ってもらえます。

## いつ・どんな場面で使うか

- 朝の身支度や通勤・通学時に「今日やったエコな行動」を思い出しながらチェックする時
- 買い物や食事のあとに、選んだ行動を記録する時
- 週末や月末に、自分がどれだけ環境に貢献できたかを振り返る時

## 使い方

1. `index.html` をブラウザで開く
2. 今日の日付が自動で選ばれた状態で表示されるチェックリストから、実施したエコ行動にチェックを入れる
3. 累計削減量・継続日数・グラフはリアルタイムで更新される。データを次回も使いたい場合は「エクスポート」でテキストをコピーして保管し、次回起動時に貼り付けて「読み込む」を押す

## データについて

入力したデータは一切外部送信されず、ブラウザ内のみで処理されます。ページを閉じるとデータは消えるため、残したい場合は必ずエクスポート機能を使ってください。
