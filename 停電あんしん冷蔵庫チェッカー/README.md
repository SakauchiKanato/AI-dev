# 停電あんしん冷蔵庫チェッカー

停電のあと「冷蔵庫の中身、食べてもいい？」と迷ったときの目安を出す、ブラウザだけで動くツールです。

## どんな機能？
- 停電時間・室温・扉を開けた回数・保冷剤の有無から「換算停電時間」を計算
- 生肉魚・乳製品・卵・惣菜・野菜・調味料・冷凍食品など12カテゴリを「食べてOK／加熱して早めに／捨てる」で判定
- 冷凍庫の詰まり具合や、一度溶けた報告にも対応
- 判定結果をテキストでコピー（家族への共有用）

## 誰のため？
一人暮らしの学生や家族。台風・地震・雷などで停電したあと、食品を捨てるか迷う人。

## 使い方
1. `index.html` をブラウザで開く
2. 停電時間・室温・扉の開閉回数などを入力する
3. 「判定する」を押して結果を見る（「結果をコピー」で共有できます）

## 注意
一般的な目安（扉を閉めた冷蔵庫は約4時間、冷凍庫は満杯で約48時間・半分で約24時間）にもとづく簡易判定です。異臭・変色があるときは判定に関わらず食べないでください。データは保存されません。
