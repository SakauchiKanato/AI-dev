# AI API料金シミュレーター

AIモデルのAPI利用料金を、タスクの想定トークン数・呼び出し回数から比較できるツールです。

## どんな機能があるか

- モデルごとの単価（100万トークンあたりの入力/出力料金）を編集・追加できる一覧表（Claude各モデル・GPT系・Gemini系・DeepSeek系などの概算値を初期登録済み）
- タスク条件（1回あたりの入力/出力トークン数・月間呼び出し回数）を入力すると、各モデルの1回あたり・月間コストを自動計算
- コストが安い順に並べ替えて一覧表示し、最安モデルとの差額を表示
- 横棒グラフでモデル間のコスト差を視覚的に比較
- 結果をワンクリックでクリップボードにコピー

## 誰のためのアプリか

ほぼ毎日開発をしてAI APIを呼び出す人向け。タスクごとにどのモデルを選ぶとコストがどう変わるかを、実装前にざっくり把握したいときに使います。

## いつ・どんな場面で使うか

- 新しい機能でAI APIを組み込む前に、想定コストを見積もりたいとき
- モデルの料金改定・新モデル登場のたびに、乗り換えでどれくらい節約できるか確認したいとき

## 使い方

1. 上部の「モデル単価」表で、実際に使う料金体系に単価を書き換える（初期値はあくまで目安です）
2. 「タスク条件」に想定トークン数・月間呼び出し回数を入力する
3. 「コスト比較」欄に安い順の一覧が自動表示される。「結果をコピー」で比較結果をテキストとしてコピーできる

## 注意事項

初期表示されている単価はすべて概算・参考値です。実際の料金はモデル提供元の最新の公式情報を確認してください。
