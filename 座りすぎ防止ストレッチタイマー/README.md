# 座りすぎ防止ストレッチタイマー

長時間のPC作業で休憩を忘れがちな人のための、シンプルなストレッチ休憩タイマーです。

## どんな機能があるか

- 25分／50分／90分のプリセット、またはカスタム分数でタイマーを開始
- タイマー終了時に、首・肩・背中・手首・目の5部位からランダムに1つストレッチを提案（やり方つき）
- タイマーを待たずにいつでも呼べる「今すぐ1分ストレッチ」ボタン
- 「実施した」「スキップ」を記録し、本日の実施回数と連続実施日数（ストリーク）を表示
- 直近7日間の実施回数を曜日別の棒グラフで表示
- ブラウザストレージを使わないため、記録を残したい場合はテキストでコピー・貼り付けして次回に引き継げます

## 誰のためのアプリか

ほぼ毎日長時間PCの前で開発をする人。集中すると休憩を忘れて肩こり・首こり・目の疲れが溜まりがちな人向けです。

## いつ・どんな場面で使うか

- コーディングや作業を始めるときにタイマーをセットしておく
- 「ちょっと疲れたな」と感じた時に「今すぐ1分ストレッチ」を押す

## 使い方

1. `index.html` をブラウザで開く
2. 作業時間のプリセット（またはカスタム分数）を選んでタイマーを開始する
3. タイマーが鳴ったら提案されたストレッチを行い、「実施した」または「スキップ」を押して記録する

記録を次回も引き継ぎたい場合は、「エクスポート（コピー）」でテキストをコピーしてメモ等に保存し、次回起動時に貼り付けて「貼り付けを読み込む」を押してください。
