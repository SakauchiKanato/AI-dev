# 忘れ物防止 持ち物チェックリスト

出かける前にサッと確認できる、シーン別の持ち物チェックリストアプリです。

## どんな機能があるか

- 通学・バイト・旅行・実家帰省など、シーンごとに持ち物リストを登録できる
- シーンを選ぶとチェックボックス付きのリストが表示され、全部チェックすると「準備完了」と表示される
- 「忘れた」ボタンを押すと、忘れた回数がアイテムごとに記録され、忘れやすいものランキングに表示される
- 季節品目（傘・日焼け止めなど）を書き込める自由メモ欄
- 全チェックを達成した日を数える「準備完了ストリーク」表示
- 登録データをテキストでエクスポート／インポートできる（保存機能は持たないため、次回起動時は貼り付けて復元）

## 誰のためのアプリか

一人暮らしの大学生など、出かける場面ごとに持ち物を忘れがちな人向け。

## いつ・どんな場面で使うか

玄関を出る直前、通学やバイト、旅行・帰省の準備をするときに使います。

## 使い方

1. `index.html` をブラウザで開く
2. 左側でシーンを選ぶ（なければ新しいシーンを追加）
3. 持ち物にチェックを入れていき、「準備完了」の表示が出たら出発

データを次回に引き継ぎたい場合は、左下の「エクスポート」でコピーした内容を、次回起動時にインポート欄へ貼り付けてください。
