# 🏠 家電・住まい点検リマインダー

一人暮らしの生活で「前回いつやったか」を忘れがちな住まいのメンテナンスを、まとめて管理・リマインドするツールです。

## どんなアプリ？

エアコンフィルターの清掃、換気扇の掃除、火災報知器の電池交換、浄水器のカートリッジ交換、排水口の掃除など、頻度がバラバラで見落としがちな住まいの点検・お手入れ項目を登録しておくと、次回やるべき日を自動計算して知らせてくれます。

## 誰のためのアプリ？

一人暮らしの大学生・社会人など、自分で住まいのメンテナンスを管理する必要がある人向けです。

## いつ・どんな場面で使う？

- 月初や週末に「今やるべき点検はあるか」を確認するとき
- 掃除・交換をしたら「実施した」を押して記録するとき
- 引っ越し後などに定期メンテナンス項目をまとめて登録したいとき

## 主な機能

- よく使う点検項目（エアコンフィルター清掃、換気扇掃除、火災報知器電池交換など）をワンクリックで追加できるプリセット
- カスタム項目を「項目名・カテゴリ・推奨頻度・前回実施日」で自由に登録
- 次回予定日を自動計算し、期限切れ（赤）・7日以内（黄）・それ以外を色分け表示
- 今週・今月にやるべき項目数をダッシュボードで一覧表示
- 「実施した」ボタンで記録を更新、実施履歴ログを蓄積
- カテゴリ（空調／水回り／防災用品／その他）で絞り込み表示
- データをテキストでエクスポート／インポート（ブラウザの保存機能は使わないため、次回開くときは貼り付けて復元してください）
- 一覧をワンクリックでクリップボードにコピー

## 使い方

1. `index.html` をブラウザで開きます
2. 左側のプリセットボタン、またはカスタム入力フォームから点検項目を登録します
3. 右側の一覧で次回予定日・状態を確認し、実施したら「実施した」ボタンを押します

## データの保存について

このアプリはブラウザの保存機能（localStorage等）を使用していません。ページを閉じると内容は消えるため、続きを使いたい場合は「エクスポート」でテキストを保存しておき、次回開いたときに「読み込む」で貼り付けてください。入力したデータは一切外部送信されず、すべてブラウザ内のみで処理されます。
