# 🗓️ 欠席ゆとりウォッチャー

科目ごとの出欠を記録して「あと何回休めるか」を色分けで確認できる出席管理ツールです。

## どんな機能があるか

- 科目ごとに授業の総回数・欠席上限（空欄なら総回数の1/3を自動計算）・遅刻の欠席換算（◯回で欠席1回）を登録
- 各回を「出席／欠席／遅刻／休講」でタップして記録（休講は総回数から除外して上限を再計算）
- 残り欠席可能回数と進捗バーを表示し、余裕／注意／危険／超過を色分け
- 全科目ダッシュボードで余裕の少ない科目から順に確認
- Markdown表としてコピー、データのエクスポート／インポート（ブラウザには保存しません）

## 誰のためのアプリか

「3分の1以上欠席すると単位不可」など、出席ルールのある授業を履修している大学生向けです。

## いつ・どんな場面で使うか

- 台風や体調不良、バイト・就活で授業を休むか迷ったとき
- 学期の途中で、各科目の欠席の余裕を一覧で確認したいとき

## 使い方

1. 科目名・総回数などを入力して「追加する」
2. 回数のマスをタップして出欠を記録（未記録→出席→欠席→遅刻→休講）
3. ダッシュボードと結果カードで残り欠席可能回数を確認。閉じる前にエクスポートしておくと、次回貼り付けて復元できます

※欠席の基準は大学・授業ごとに異なります。必ず履修要項・シラバスで確認してください（あくまで目安です）。
