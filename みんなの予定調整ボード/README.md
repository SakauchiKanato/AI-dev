# みんなの予定調整ボード

友人・サークル・アルバイト仲間との日程調整を、LINEなどで「コード」をやり取りするだけで完結させるツールです。

## どんな機能があるか

- 主催者: イベント名と候補日時（何件でも）を入力すると「イベントコード」を作成
- 参加者: イベントコードを貼り付けると候補日時が復元され、名前と各候補への回答（◯参加可／△未定／×不可）から「回答コード」を作成
- 主催者: 全員の回答コードをまとめて貼り付けると、候補日時×参加者の一覧表に自動集計。スコア（◯=2点・△=1点・×=0点）が最も高い候補をハイライト表示
- サーバーを使わないため、外部への送信や保存は一切なし（コードはLINEやメールなどこのアプリの外でやり取りする前提）

## 誰のためのアプリか

友人・サークル・アルバイト先など、複数人での集まりの日程を決めたい人向け。個別に予定を聞いて回る手間を減らせます。

## いつ・どんな場面で使うか

飲み会や集まりの候補日を決めたい時、複数の候補日時に対してみんなの都合を一覧で見比べたい時に使います。

## 使い方

1. 主催者が「①イベント作成」タブでイベント名・候補日時を入力し、生成された「イベントコード」をコピーして参加者に送る
2. 参加者は「②回答する」タブでイベントコードを貼り付け、名前と各候補への回答を選んで「回答コード」を作成し、主催者に送り返す
3. 主催者は「③集計する」タブでイベントコードと全員分の回答コードをまとめて貼り付け、「集計する」を押すと結果が一覧表示されます
