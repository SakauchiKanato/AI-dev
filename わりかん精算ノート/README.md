# わりかん精算ノート

友人との飲み会・旅行・共同購入などで発生した立替払いを、送金回数が最小になるよう自動で精算してくれるツールです。

## どんな機能があるか

- 参加者の登録（人数分、自由に追加・削除可能）
- 立替払いの記録（誰が・いくら・何のために払ったか）
- 精算方式の選択: 均等割り、または参加者ごとの重み付けによる傾斜配分
- 支払い総額・参加人数・1人あたり負担額（均等時の目安）をダッシュボード表示
- 「誰が誰にいくら送金すればよいか」を最小送金回数になるよう自動計算して一覧表示
- 精算結果をワンクリックでクリップボードにコピー

## 誰のためのアプリか

友人との飲み会・旅行・共同購入などでまとめ払いが発生した際、割り勘の精算計算が面倒な大学生など向け。

## いつ・どんな場面で使うか

飲み会や旅行が終わって「結局誰が誰にいくら払えばいいんだっけ」となったその場で開いて使います。傾斜配分（重み）を使えば、飲んだ量や部屋の広さの違いなど、単純な均等割りにしたくない場面にも対応できます。

## 使い方

1. 「参加者」欄に名前を入力して全員を登録する
2. 「立替払いの記録」欄で、支払った人・金額・用途（任意）を入力して記録する（複数回記録可）
3. 精算方式（均等割り／傾斜配分）を選ぶと、下部に送金指示（誰が誰にいくら払うか）が自動表示される。「結果をコピー」で内容をそのまま友人に共有できる

## 補足

- ブラウザで index.html を開くだけで動作します（サーバー・外部APIキー不要）
- データはブラウザを閉じると消えます（保存が必要な場合はコピー機能を使ってメモしてください）
