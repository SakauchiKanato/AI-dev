# JWTデコーダー＆検証ツール

JWT（JSON Web Token）を貼り付けるだけで中身を確認できる、開発者向けのブラウザツールです。入力したトークンや鍵は一切外部送信せず、ブラウザ内のみで処理します。

## どんな機能があるか

- JWTを貼り付けると Header / Payload / Signature の3パートに分解し、Header・Payloadを見やすい色付きJSONで表示
- `exp`（有効期限）・`iat`（発行時刻）・`nbf`（有効開始）を人間が読める日時に変換し、期限切れなら赤いバッジで警告
- よく使うクレーム（sub / iss / aud / exp / nbf / iat / jti / alg）の早見表を常時表示
- HS256アルゴリズムの署名検証（秘密鍵を入力して一致・不一致を判定。RS256など非対称鍵方式は非対応と明記）
- HeaderとPayloadをJSONで自由編集し、秘密鍵を指定してHS256の新しいJWTをその場で生成
- デコード結果・生成したトークンはワンクリックでクリップボードにコピー可能

## 誰のためのアプリか

ほぼ毎日開発をしていて、認証周りの実装・デバッグでJWTを扱う人向け。

## いつ・どんな場面で使うか

- ログイン処理をデバッグしていて、APIのAuthorizationヘッダーに入っているJWTの中身を確認したいとき
- トークンの有効期限切れが原因かどうかをすぐ確認したいとき
- テスト用のJWTをその場でサクッと組み立てたいとき
- 外部のJWTデコードサイトに機密情報を含むトークンを貼り付けたくないとき

## 使い方

1. `index.html` をブラウザで開く
2. 上部の入力欄にJWTを貼り付けて「デコードする」を押す（お試しには「サンプルを読み込む」ボタンが使える）
3. 必要に応じて②の署名検証、または③の新規JWT生成パネルを使う

## 補足

- 署名検証・生成はHS256（共通鍵方式）のみ対応しています。RS256・ES256など公開鍵方式のトークンはデコード表示のみ可能です。
- ブラウザストレージは使用していないため、ページを閉じると入力内容は消えます。
