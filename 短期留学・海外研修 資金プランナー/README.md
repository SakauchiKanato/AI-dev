# 短期留学・海外研修 資金プランナー

短期留学や海外研修にかかる総費用を為替込みで試算し、出発までの貯金計画が間に合うかを判定するアプリです。

## どんな機能があるか
- プログラム費用・航空券・保険・ビザ・現地生活費（外貨×日数×為替）・予備費から総額を計算
- 内訳の割合バーと、為替が±10円・±20円動いた場合の総額の変化表
- 出発日までの月数から、貯まる見込み額・不足額・必要な月額の目安を判定
- 節約・見直しのヒントと、結果のコピー機能

## 誰のためのアプリか
短期留学・語学研修・海外研修に申し込むか迷っている大学生。

## いつ使うか
申込前の費用の見積もり、家族への相談前、積立計画を立てるとき。

## 使い方
1. index.html をブラウザで開き、募集要項などの金額を入力する（初期値は仮の数字です）
2. 結果欄で総額・判定・為替の影響を確認する
3. 「結果をコピー」でメモや相談用に書き出す

※ 入力内容はこのページを開いている間だけ保持され、保存・送信されません。金額は目安です。
