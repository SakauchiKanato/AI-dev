# 就活イベント締切トラッカー

就活イベントの案内・エントリー締切をうっかり見逃さないよう、一元管理するツール。

## どんな機能があるか

- 企業名・イベント内容・種別（説明会／ワークショップ／エントリー／選考／その他）・開催日時・締切日・URL・メモを登録
- 締切が近い順に一覧表示。当日・期限切れは赤、3日以内は黄で警告表示
- 「本日締切」「本日開催」「期限切れ」をダッシュボードで一目確認
- ステータス管理（未対応／エントリー済み／参加した／見送り）で進捗を管理
- 今後7日間の予定をカレンダー風に一覧表示
- 登録データをテキストでエクスポート／インポート可能（ブラウザに保存されないため、閉じる前に保存しておく）

## 誰のためのアプリか

複数の就活プラットフォーム（TIIS・日立・バンダイナムコ・gakujoなど）からメールで届く多数のイベント案内・締切を管理しきれない、就活準備中の大学生向け。

## いつ・どんな場面で使うか

- 就活イベントの案内メールを受け取った直後の登録
- 朝・出かける前に「今日締切・開催のもの」を確認する時
- 週の予定を見通したい時

## 使い方

1. `index.html` をブラウザで開く
2. 「新規登録」フォームに企業名・内容・締切日などを入力して「登録する」を押す
3. 一覧やダッシュボードで締切・開催状況を確認し、対応が終わったらステータスボタンで更新する

※ブラウザを閉じるとデータは消えます。継続して使う場合は「エクスポート/インポート」パネルで書き出したテキストを保存し、次回起動時に貼り付けてください。
