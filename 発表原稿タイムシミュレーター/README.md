# 発表原稿タイムシミュレーター

ゼミ発表・プレゼン・口頭試問などの原稿を貼り付けるだけで、持ち時間に収まるかを声に出さずに確認できるツールです。

## どんな機能があるか

- 発表原稿を貼り付けると、日本語・英数字が混在していても文字数を概算し、話す速度（200〜400字/分でスライダー調整可能、デフォルト300字/分）から推定発表時間を自動計算します
- 目標時間（分）を入力すると、推定時間との差を色分け表示します（超過:赤、ほぼ目標どおり:緑、余裕あり:黄）
- 原稿を空行で区切ると、セクションごとの文字数・推定時間が一覧表示され、どの部分が時間を圧迫しているか一目で分かります
- 話す前の「間・一時停止」の秒数を追加設定し、合計時間に反映できます
- 結果一覧をワンクリックでMarkdown形式にコピーできます（コピー失敗時は自動でフォールバックします）

## 誰のためのアプリか

ゼミ発表・プレゼン・口頭試問などの発表原稿を用意する大学生向けです。

## いつ・どんな場面で使うか

発表原稿を書き終えたあと、実際に声に出して読む前に「時間内に収まりそうか」をざっくり確認したいときに使います。

## 使い方

1. 上部のテキストエリアに発表原稿を貼り付けます（空行を挟むとセクションごとに集計されます）
2. 話す速度のスライダーと目標時間（分）を自分の発表に合わせて調整します
3. 右側のダッシュボードに推定時間と判定が表示されるので、超過している場合は原稿やセクションを見直します

## 入力データについて

入力した原稿はこの画面の中だけで処理され、外部には一切送信されません。ブラウザの保存機能（localStorage等）も使用していないため、ページを閉じると内容は消えます。
