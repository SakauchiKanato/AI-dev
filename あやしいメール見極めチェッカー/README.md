# あやしいメール見極めチェッカー

受け取ったメールやSMSが詐欺・フィッシングの可能性がないか、その場でセルフチェックできるツールです。

## どんな機能があるか

- 差出人メールアドレスと本文（URL含む）を貼り付けるだけで判定
- 9種類の危険信号をヒューリスティックに検出
  - 緊急性を煽る文言（今すぐ・口座凍結など）
  - 金銭・個人情報の要求（パスワード・認証コードなど）
  - 短縮URLの使用
  - クリックを促すリンク誘導
  - IPアドレス形式のURL
  - 実行形式ファイルへの言及
  - 個人名の入らない一律の宛名
  - 名乗る企業名と差出人アドレスの不一致
  - 不自然な日本語表現の兆候（簡体字混入・機械翻訳調の言い回しなど）
- 検出した危険信号を理由付きカードで一覧表示
- 総合危険度を4段階（低・中・高・非常に高い）で色分け表示
- よくある詐欺の手口早見表（フィッシング・架空請求・当選詐欺・サポート詐欺・なりすまし）を常時表示
- 判定結果をワンクリックでクリップボードにコピー

## 誰のためのアプリか

メールやSMSで怪しい連絡を受け取った人なら誰でも使えます。日々の自動配信メールを仕分けるメール秘書の業務を、受信者自身が詐欺の観点でセルフチェックできるように補完する位置づけです。

## いつ・どんな場面で使うか

「このメール、本物かな？」と少しでも不安に思った時。リンクを踏む前・個人情報を入力する前のセルフチェックとして使います。

## 使い方

1. 差出人メールアドレス（わかれば）と、本文をそのまま貼り付ける
2. 「判定する」ボタンを押す
3. 総合危険度と、検出された危険信号の理由を確認する

※ ヒューリスティックによる簡易チェックのため100%の判定は保証しません。少しでも不安な場合は、メール内のリンクや電話番号を使わず、公式サイト・公式アプリから直接確認してください。
